# Madam Mori — Memory across your AI tools

Version 0.4.7 · chatgpt

Keep your projects, decisions and preferences connected across supported AI tools.

## Install the complete package

```text
This is a review/import candidate, not a published or universally installable ChatGPT listing.
Use a supported private marketplace/admin import or complete public directory review and actual host OAuth registration first.
```

After the host has installed the complete package and authorized the account, run its Mori setup skill in a fresh chat. Do not claim normal-Chat support until tested there.

Sign in or register on https://www.mdmori.com with Google or email, approve the named Mori permission screen, and return to your AI. No Mori web harness or AI-subscription sign-in is required for Memory-only access. Never paste credentials into chat.

## Verify before calling it ready

Check all three bundled skills are available: mori-setup, mori-memory, mori-reconnect. Confirm all nine tools are exposed: mori_open, mori_status, mori_browse, mori_search, mori_remember, memory_numeric_menu, memory_numeric_submit, memory_numeric_retrieve and memory_numeric_read; account authorization succeeds, and mori_status reports Core ready. An empty graph is a valid connected state. These are separate checks; installing files alone proves none of them. An optional user-chosen read-only recall check must report empty results honestly. No persistent test writes are required.

## Included

Connector configuration, three skills, branding assets, setup/reconnection guidance and optional project instruction snippets. AGENTS.md / CLAUDE.md snippets are not automatically loaded from a plugin root; merge only on request, preserving existing project instructions. No hooks, private credentials or customer memory are bundled. The included Archivist JavaScript helper uses only the host-provided authenticated tool callback and private audit journal; it has no embedded credentials or network endpoint.

## Limits and recovery

Automatic skill selection is host/model dependent. Direct MCP setup connects tools but does not install skills. Do not install a second connector if one already works; enable the full plugin and reuse the existing account. The four Numeric tools preserve the full Core contract: exact-ID delete/revise, history, evidence, pagination, following relationships, promote, split, merge and link ADD. These operations require current menus, permitted selections and explicit consent; Core may reject or quarantine a proposal. Deletion preserves immutable evidence and audit history. Relink REMOVE is not implemented by Core and is not advertised. Read-only authorization never permits saving. Reconnect or remove access at https://www.mdmori.com/profile/security. Help: https://www.mdmori.com/connect/memory#help.
